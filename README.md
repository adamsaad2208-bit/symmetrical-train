## ValueMart — retail homepage study clone

A static front-end recreation of a big-box retailer homepage layout (blue header with
search, department nav, hero carousel + tile grid, flash-deals shelf with countdown,
popular shops, product shelves, promo tiles, footer). Branding is a fictional
"ValueMart" — no real logos, images, or trademarks are used.

Open `index.html` in a browser — no build step. Files: `index.html`, `styles.css`, `script.js`.

Interactive bits: auto-rotating hero carousel, scrollable product shelves, add-to-cart
counter/total with toast, favorite toggles, live countdown, responsive down to phone width.
